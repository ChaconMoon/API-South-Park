## Añadidos a la API {.blog_title}

### Nuevos personajes {.blog_subtitle}

Empecemos por los personajes, se han añadido todos los personajes desde [Kanye West (personaje 1000)](/api/characters/1000) hasta [Kylo Ren (personaje 1048)](/api/characters/1048) Oficialmente tenemos mas de 1000 personajes en la API y vamos solo por la K, aun queda mucho camino, cuando termine la API llegaremos facilmente a los 2500 personajes, especialmente por la M. hay demasiados Mr.(algo) o Mrs.(algo), de hecho adelanto que esa actualización serán 2 actualizaciónes, en plan Cliffs and Caves de Minecraft, será las versiones Misters and Misses Parte 1 y Misters and Misses Parte 2

### Arreglo de errores. {.blog_subtitle}

Con el lanzamiento de la Fortnite Update llegarón multiples errores

- Se ha corregido un error tipografico en el que en la sección items de fortnite se usaba la palabra items en singular en lugar de usarla en plural: /api/fortnite/item/1/image -> /api/fortnite/items/1/image
- Se ha añadido el objeto [Cheesy Poofs]( /api/fortnite/items/3/) que no se añadio en la actualización original.

### Cambios en los endpoints de Fortnite. {.blog_subtitle}

Se ha añadido la opción de filtrar en los endpoints de Fortnite.

- Filtrar por tipo. Ejemplo (skin): [/api/fortnite/cosmetics/?type=Skin](/api/fortnite/cosmetics/?type=Skin)
- Filtrar por precio. Ejemplo (1500 V-Bucks): [/api/fortnite/cosmetics/?price=1500](/api/fortnite/cosmetics/?price=1500)
- Filtrar por rareza. Ejemplo (Epic): [/api/fortnite/cosmetics/?rarity=Epic](/api/fortnite/cosmetics/?rarity=Epic)

(Estos filtros pueden usarse combinados.)

Tambien se ha añadido la opción de mostrar un listado de los cosmeticos de Fortnite [/api/fortnite/cosmetics/](/api/fortnite/cosmetics/)

Se ha habilitado la opción de buscar en los items de fortnite.

[/api/fortnite/items/?search=Kenny](/api/fortnite/items/?search=Kenny)

## Despedida. {.blog_title}

Se que queda un poco raro seguir con el desarrollo de la API tras tanto tiempo, pero sigo queriendo buscar el metodo de financiar un server para la API, si que como nadie esta usando la API no le veo mucha motivación aun asi este proyecto me apasiona y luchare por donde pueda para sacarla adelante, de momento puedo decir que como docenete de programación me ha servido, tengo aqui el ejemplo perfecto de como desplegar un proyecto completo, de hecho si hubiera desarrollado este proyecto durante mi epoca de estudiante hubiera tenido trabajo casi seguro.

Veo los proyectos de mis alumnos y aunque obviamente tienen mucha menos complejidad tienen un nivel bastante bueno, les falta ser mas solidos.

Considero que este proyecto es lo bastante solido para considerarse un proyecto totalmente serio, aunque me falta mucho por mejorar. Pero os garantizo que termiare la API y lo mas importante haré que se me conozca por ello. De momoento soy un don nadie, pero algún dia sere alguien.
